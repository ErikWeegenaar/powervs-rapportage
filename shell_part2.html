How to use this tool

This is a self-contained HTML file — no installation, login, or internet connection required. Open it in any browser (Chrome, Edge, Firefox). Nothing you do here changes anything in the live IBM Cloud account.

1. Find what you're looking for
  • Search box — type any part of a name, group, product, tag, or IP address. Results update as you type.
  • Dropdown filters — narrow results by category, environment/cluster, or status. Combine multiple filters at once; click Reset filters to start over.
  • Column sorting — click any column header to sort by that column; click again to reverse the order.
  • Row details — rows with a ▶ arrow can be clicked to expand and show extra details (Power VS workspace, OpenShift metadata, resource group, tags).
2. Jump straight to what needs attention

Open the Action Needed tab for a ready-made shortlist: servers currently in a Warning state, and Power VS workspaces with no active servers. This is the fastest way to start a health check without scrolling through all 488 resources.

3. Export data to Excel / Google Sheets

Every tab has an ⬇ Export CSV button. It exports exactly what is currently visible — i.e. your active search and filters are respected. Opening the downloaded .csv file in Excel or Google Sheets lets you pivot, chart, or share the data further.

4. Sharing this tool with others

Because it's a single HTML file, you can send it by email, Teams, or upload it to a shared drive (e.g. Box). Anyone who opens it sees the exact same data — there is no live connection back to IBM Cloud, so updates made in IBM Cloud after this snapshot was taken will not appear automatically. See the note below on keeping this up to date.

About this data

This tool combines four data sources collected from IBM Cloud and Red Hat OpenShift on October 23, 2026, for account 2330274 — GBS c/o Schiphol:

  1. IBM Cloud Resource List (cloud.ibm.com/resources) — 488 active resources across 8 categories (Storage, Compute, Networking, Containers, Developer tools, AI/Machine Learning, Observability, Security).
  2. Power Virtual Server Workspace Details (cloud.ibm.com/power/workspaces) — detailed inventory of 278 resources (servers, storage volumes, subnets, boot images) across 6 workspaces in eu-de-1 and eu-de-2, fully linked to the main resource list (251 by direct name match, 27 resolved via internal resource IDs). Server, volume, subnet, and image details (IP, OS, cores, memory, size, tier, pool, VLAN) are parsed into their own columns, available directly in the "All Resources" table and in each row's expanded detail view.
  3. Red Hat OpenShift Console data — cluster health, version, and control-plane/compute node counts for 6 OpenShift clusters running on top of the Power infrastructure.
  4. FRA05 LPAR & Server inventory — physical host to virtual machine mapping for 42 VMs, including CPU/memory allocation and RMC (Resource Monitoring and Control) agent status.

Use the All Resources tab to browse, search and filter every resource, with IP/OS/Cores/Memory shown directly as columns. Click a row to expand it for extra details (host, OpenShift metadata, tags).
